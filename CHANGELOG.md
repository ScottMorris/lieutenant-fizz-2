# Changelog

## Unreleased

- Start the repository: house rules, the `fizz-sim` fixed-tick and state-hash foundation, documentation and the animated README banner.
- Add the Milestone 0 platform skeleton: a marker moved by input at a fixed 60 Hz on Web and DOS, with the same state-hash transcript on native x86_64, Web (WASM) and DOS (headless DOSBox), compared by `tools/check-parity.sh` and a `parity` CI job in the pinned `ci-dos` image. It adds `fizz-hello` (throwaway rules), `fizz-hal`, `fizz-present-dos`, `fizz-present-web`, the `dos/` workspace with its runtime and `FIZZ2.EXE`, the Web page, and `docs/PLATFORM.md`. `InputFrame` and its types now live in `fizz-sim`.
- Add the Fizz 2 Progress Report, a living archive generated by `tools/progress-report/` from `git`, `gh` and the tree: chapters from the proof of concept to Milestone 0, the parity gate and the merged stack, a roadmap of Milestones 1 to 5, diagrams in the EGA palette, charts, step-throughs, and DOSBox and headless Chromium screenshots with how each was captured. Its tests and a dry run of its gatherer run in `tools/check.sh`, and its prose follows `tools/progress-report/VOICE.md`.
- Add `fizz-ep2` with Ben's movement ported from Fizz 1's `tick_ben_move` and proved bit for bit against Fizz 1's golden traces for ten scenarios (fall, run, jumps, pogo, ceiling, one-way platforms, wall and step-up, slopes). Velocities below 2^-1000 snap to zero, a documented departure from Fizz 1.
- Finish the slice's rules in `fizz-ep2`: the chicken (Fizz 1's Gloop), the Fizz Blaster shots, the red key and door as `WorldFlags`, spikes, death and respawn, and the exit, ported from Fizz 1 and proved bit for bit by the six scenarios that were ignored (`gloop_patrol`, `stomp`, `stomp_pogo`, `fizz_stun`, `key_door`, `route`). Add the hand-written 32 by 48 slice level as `const` data, the slice state hash with a test that locks its field order, and a 1,268-tick scripted replay with transcript `SLICE REPLAY 1` and a golden file. No presenter runs it yet.
- Grow `fizz-view` for the first playable slice: `tile_px`, the y-flip `screen_y`, a stateless clamped `follow` camera, and clipped `blit_sprite`, `fill_rect` and `draw_tilemap` over a palette-indexed frame buffer. Nothing player-visible changes; the presenters adopt them with the slice.
- Play the slice on DOS. Add `fizz-slice-view`, the one routine (`draw_slice`) that draws the slice into a palette-indexed buffer for both presenters, with the follow camera, Fizz 1's Ben, the Cluckzarg placeholder chicken, the key, the door and the shots. `FIZZ2.EXE` with no arguments or `/LIVE` now plays the slice with a text HUD of ammo, key, deaths and tick; `/SLICE` runs the slice script and prints its transcript; `/REPLAY` still prints the Milestone 0 one. `tools/check-dos.sh` checks the DOS transcript against `slice-replay.txt` (`FINAL TICK 1268 HASH d1a225bf14ab4828`). `FIZZ2.EXE` grows from 32,768 to 71,168 bytes.
