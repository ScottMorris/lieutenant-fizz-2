Climb the lighthouse: fetch the red key, walk into the red door with it, and reach the exit. Mind the spikes and the chicken.

Arrow keys move, Ctrl jumps, Alt uses the pogo stick, Space fires.

A browser tab keeps a few shortcuts for itself, such as Ctrl+W, and some desktops keep window and workspace shortcuts, so the game cannot block them. If one gets in the way, switch to the Modern keys, which avoid them. In fullscreen, Chromium browsers can hold Ctrl and Alt for the game. The chicken clucks, but a browser only allows sound after you press a key or click, so it starts then.
